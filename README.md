# Персональный сайт-портфолио Алисии
Этот проект — персональный веб-сайт - визитка, созданный в рамках итоговой аттестации "Код будущего". Сайт представляет владельца, его увлечения, достижения и предоставляет форму для обратной связи.
## Цель проекта
Разработать современный, адаптивный и интерактивный одностраничный сайт с несколькими разделами (многостраничная навигация без перезагрузки), который:
- Знакомит посетителей с личностью, навыками и интересами автора.
- Демонстрирует ключевые достижения (спортивные, волонтёрские, творческие) через карточки с раскрывающимся описанием.
- Предоставляет форму обратной связи с клиентской валидацией.
- Поддерживает светлую и тёмную тему с сохранением выбора пользователя.
- Корректно отображается на любых устройствах (десктоп, планшет, мобильный телефон).
## Использованные технологии
- **HTML5** — семантическая разметка (header, main, footer, section, article, nav).
- **CSS3** — стилизация, адаптивная вёрстка (Flexbox, Grid), анимации (hover, плавное раскрытие блоков), медиазапросы.
- **JavaScript (ES6)** — управление навигацией между страницами, переключение темы с сохранением в localStorage, валидация формы, аккордеон для карточек увлечений.
- **LocalStorage** — сохранение текущей страницы и выбранной темы при перезагрузке.
- **GitHub Pages** — хостинг статического сайта.
## Структура и функциональность
Сайт состоит из пяти разделов (страниц), переключение между которыми происходит без перезагрузки страницы:
1. **Главная** — приветственный блок с аватаркой, кратким представлением и кнопкой «Связаться со мной» (ведёт на форму контактов).
2. **Обо мне** — текстовая информация об увлечениях, спортивном разряде, изучении языков, творчестве.
3. **Увлечения** — четыре карточки (Путешествия, Добровольческая деятельность, Спорт, Творчество). При клике на карточку под ней раскрывается подробное описание с возможными ссылками на внешние ресурсы. Ссылки оформлены как кнопки и открываются в новой вкладке.
4. **Блог** — заглушка с двумя короткими постами (можно расширять в будущем).
5. **Контакты** — форма обратной связи: поля email, телефон (необязательно), сообщение. Реализована проверка заполнения email и сообщения, данные выводятся в консоль.
**Дополнительно:**
- Переключатель светлой/тёмной темы (иконка луны/солнца) сохраняет выбор в `localStorage`.
- При перезагрузке страницы восстанавливается последний открытый раздел.
- Футер с копирайтом и ссылками-заглушками на социальные сети.
- Адаптивный дизайн: на мобильных устройствах меню и шапка выстраиваются в колонку, карточки подстраиваются под ширину экрана.
